# reel mode

Use `scripts/reel.sh` to acquire the actual media, transcript, frames, and
metadata. If acquisition fails, inspect the script's local dependency checks
and report the missing capability. Do not assume a vendor-specific runtime,
plugin root, remote service, or deployment path.

Never summarize a media URL from its URL text, caption, thumbnail, or remembered context. Inspect audio and representative frames. For a carousel or photo post, inspect every image in order.

Return a bounded account of what is visible, what is said, the structure, reusable creative patterns, and uncertainty. Do not download or persist media beyond the task's working area unless requested.
